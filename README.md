Krisaanjh - Farmer-Company Mediator Platform
A blockchain-based platform connecting farmers directly with large companies using smart contracts for transparent and fair transactions.

🚀 Technologies Used
🌐 Frontend
React.js (UI framework)

Material-UI (MUI) (UI components & styling)

Redux (State management)

Axios (API communication)

🔗 Backend & Blockchain
Node.js & Express.js (Server & API)

MongoDB (Database)

Ethereum/Solidity (Smart contracts)

Web3.js/Ethers.js (Blockchain interaction)

🛠 DevOps & Tools
Docker (Containerization)

Git & GitHub (Version control)

Firebase (Authentication/Hosting) (if applicable)

📌 Key Features
✔ Smart Contract Automation – Secure, self-executing agreements between farmers & buyers.
✔ Transparent Pricing – Blockchain ensures fair pricing and reduces middlemen.
✔ Real-Time Tracking – Monitor crop quality, delivery, and payments in real time.
✔ Direct Farmer-Company Deals – Eliminates intermediaries for better profits.

⚡ How to Run?

Clone the repo
git clone https://github.com/suryansh0010/krisaanjh.git
cd krisaanjh

Install dependencies
npm install  # Frontend
cd server && npm install  # Backend

Set up environment variables (.env for backend & blockchain config)

Run the app
npm start  # Frontend
npm run dev  # Backend

💡 Why Krisaanjh?
Farmers often face exploitation due to opaque supply chains. Krisaanjh leverages blockchain to ensure fair pricing, instant payments, and trustless agreements—empowering farmers while optimizing corporate sourcing.
